## 17. 리아 협동(성광 협공) & 스테이지·구역 확장 (v5.6.0-build460, Step 4-3, 2026-11-24)

### 17-1. 리아 협동 — 성광 협공 (`js/battle.js` · `G.COOP`)

궁극기(`L` · 빛의 심판)와 **다른 축**입니다. 같은 리아의 힘을 쓰지만 자원·연출·지속이 달라서 섞어 쓰면 서로를 보완합니다.

| | 궁극기 `L` · 빛의 심판 | 협동 `R` · 성광 협공 |
|---|---|---|
| 자원 | 리아 MP 40 | 협동 게이지 100 |
| 지속 | 순간 (빛기둥 1회 광역 폭딜) | **8초** 지속 결계 |
| 연출 | 보랏빛 사선 컷인 + 소환 마법진 + 빛의 기둥 | **금빛 사선 컷인** + 성문 빛의 결계 + 리아 SD 필드 합류 |
| 효과 | 광역 3.4배 피해·넉백 | 즉시 회복 8% · 받는 피해 ×0.6 · 공격력 ×1.18 · **성광 호응타** |
| 쿨타임 | 13초 | 10.5초 (지속 종료 후) |

- **게이지**: 전투 중 초당 5.5씩 차오르고, 카엘이 적을 맞힐 때마다 +1.6, 처치마다 +6. 100이 되면 HUD 협동 버튼이 금빛으로 맥동합니다.
- **발동**: 리아의 금빛 사선 컷인(`CO-OP · 성문 빛의 결계`) → 화면 플래시 → 카엘 발치 빛기둥 →
  반원형 **성문 빛의 결계**가 카엘을 감싸고, 리아 SD가 카엘 뒤편에 내려와 따라다닙니다.
- **성광 호응타**: 결계 중 카엘이 적을 맞히면 0.11초 뒤 리아의 빛이 같은 자리에 꽂힙니다
  (공격력의 0.5배, 최소 간격 0.05초, 사거리 470px). 맞은 적이 그 사이 쓰러지면 근처에 남은 적에게 대신 꽂힙니다.
- **결계**: 받는 피해 ×0.6, 공격력 ×1.18. 지속이 끝나면 결계가 옅어지며 리아가 사라지고, 그때부터 쿨타임이 흐릅니다.
- **HUD**: 우측 하단 점프 버튼 위에 협동 버튼. 테두리 링이 게이지, 가운데 글자는 `R` → 준비되면 금빛 맥동,
  지속 중에는 남은 초(`7`), 대기 중에는 쿨타임 초를 보여 줍니다. 버튼 아래 라벨은 `준비 / 협동 중 / 대기 / 충전 %`.
- 키는 **R 과 C 둘 다** 받습니다(모바일은 버튼). 일시정지·화면 이탈 시 보관 입력이 새지 않도록 `queuedCoop`도 함께 초기화합니다.

조작(←/→·W/S·↑/Space 점프·J/K/L/Shift/R·오토 3모드)과 정면 반원·리치·깊이 레인 기준은 그대로입니다.

### 28-1. 무엇이 어긋나 있었나 (`js/battle.js` `_skillHit`)

- 일반 적: `Math.abs(e.x - cx) < radius && Math.abs(e.y - cy) < radius * 0.75` (X·깊이 둘 다)
- 보스: `front(boss.x) && Math.abs(boss.x - cx) < radius + 40` — **깊이 판정이 없음**
- 그래서 보스가 다른 레인(y가 다른 자리)에 있어도 스킬 중심점 AoE 안이면 피격됐습니다(본편·외전 같은 구조).
- 이제 보스도 `&& Math.abs(this.boss.y - cy) < radius * 0.75` 를 함께 봅니다. 판정 기준 `cy` 는 스킬 AoE 중심의 **발 y**
  (히어로 중심 스킬은 `h.y`, 대상 중심 스킬은 대상의 `y`)로, 일반 적 분기와 같은 값입니다.

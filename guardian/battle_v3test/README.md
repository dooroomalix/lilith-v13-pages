# 마지막 성문의 수호자 · 전투 v2 (플레이 가능한 프로토타입)

목표 목업(`attachments/2026-11-16/81167-...jpg` 2번 장면 — 실제 플레이 전투/AUTO 진행 중)의 화면을
**브라우저에서 실제로 돌아가는 모바일 가로 액션 전투**로 구현한 프로토타입입니다.

- 엔진: **PixiJS v8.6.6** (로컬 번들 `vendor_pixi.min.js`, 외부 빌드/네트워크 불필요)
- 해상도: 논리 좌표 **1280×720 (16:9)**, 렌더 해상도는 DPR 최대 2배(레티나 선명도)
- 세로로 열면 **가로 회전 안내 오버레이**가 표시됩니다.
- 폴더: `projects/guardian/battle_v2/`

---

## 1. 실행 방법

```bash
cd projects/guardian/battle_v2
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속 (모바일은 PC와 같은 Wi-Fi에서 http://<PC IP>:8080)
```

- 정적 파일만으로 동작하며 빌드 과정이 없습니다. `index.html`을 직접 열어도 대부분 동작하지만,
  BGM/이미지 로딩이 브라우저 정책에 막히는 경우가 있어 **로컬 서버 사용을 권장**합니다.
- 첫 터치/클릭에서 BGM이 시작되고, 우측 상단 스피커 아이콘 또는 일시정지 메뉴에서 음소거할 수 있습니다.

### 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 이동 | 좌하단 가상 조이스틱 드래그(화면 좌측 아무 곳) | `WASD` / 방향키 |
| 공격(3연타 콤보) | 우하단 검 버튼 | `Space` / `J` |
| 스킬1 · 성문의 참격 | 파란 버튼 | `K` |
| 스킬2 · 빛의 심판 | 보라 버튼 | `L` |
| 회피 / **퍼펙트 카운터** | 회피 버튼(흰색) | `Shift` |
| AUTO 모드 순환 | `AUTO` 토글 | `T` |
| 일시정지 · 음소거 | 우측 상단 `II` / 스피커 | `Esc`/`P` · `M` |

**AUTO 3단 모드** (기본: 반격만 수동)
1. `완전 오토` — 이동·공격·스킬·회피·퍼펙트 카운터까지 자동
2. `반격만 수동` — 전투는 자동, **보스의 흰색 예고에서만** 직접 회피 버튼을 눌러 카운터
3. `완전 수동` — 모든 조작을 직접

## 2. 구현된 전투 흐름

1. **스테이지 인트로** → 터치하면 전투 시작 (BGM 재생)
2. **일반전 60초** (`01:00` 카운트다운, 지역명 `폐허의 거리`)
   - 그림자 정찰병 웨이브 4단(4→5→6→6마리)이 우측에서 접근, HP/Lv 표시
   - 전멸 시 다음 웨이브, 웨이브 클리어마다 카엘 HP 소량 회복
3. **보스전** (`03:00`, 지역명 `폐허의 왕좌`)
   - `그림자 군주 · 아르카논` (HP 30,000) 등장 — 카메라 줌/셰이크/포효 연출
   - 패턴: **홍색 광역 강타**, **황색 3연 참격**, **백색 예고(퍼펙트 회피)**, 소환
   - 흰색 예고의 마지막 구간에서 회피하면 **PERFECT COUNTER** — 보스 경직 + 980 피해 + 슬로우 연출
4. **승리/패배** 결과 패널(누적 피해·최대 콤보·처치 수·남은 시간) → `다시 도전`

전투 템포: 일반전은 20~30초 안에 정리되고, 보스는 대략 45~70초에 처치되도록 수치를 잡았습니다
(무입력 방치 시 3분 내외로 패배).

## 3. 연출 요소 (목업의 타격감 구현)

- **검기 슬래시**: PixiJS `add` 블렌드의 3겹 크레센트(외곽 청색 → 중간 하늘색 → 백색 코어)가
  회전·확장하며 사라지는 궤적 + 잔검 파편 파티클
- **타격 버스트**: 방사형 섬광(불규칙 길이의 얇은 광선 16개) + 코어 글로우
- **데미지 숫자**: 일반(흰색)/크리티컬(금색, 더 크게) 숫자가 솟아오르며 페이드, 다중 타격 시 위치 분산
- **히트스톱 50ms + 화면 셰이크**: 실제 시간의 8%로 감속 후 복귀
- **퍼펙트 카운터**: 0.85초 슬로우, 확대, 충격파 링, 황금 버스트
- **몬스터 피격**: 가산 블렌드 실루엣 플래시 + HP바 갱신 + 사망 시 차원 균열 링
- **배경**: 황혼 폐허 원화를 패럴랙스 드리프트 + 줌 브리싱, 안개 2겹, 빛줄기 3개,
  불티 44개, 접지 그라데이션, 비네트
- **사운드**: 보스전 BGM(`audio/boss_bgm.mp3`, 3분41초 트랙 루프) + WebAudio 절차적 효과음
  (검기 휘두름/타격/마법/카운터/보스 포효/UI)

## 4. 화면 구성 (HUD)

- **좌상단** `Lv.1 카엘` 초상화 프레임 + HP 바(초록, 세그먼트) + MP 바(파랑) + 수치
- **상단 중앙** 보스전에서 보스 HP 바 + 이름
- **우상단** 지역명 · 타이머(`01:00` / `03:00`) · 일시정지 · 음소거 · 미니맵(아군/적/보스 점, 시야 콘)
- **좌하단** 반투명 가상 조이스틱
- **우하단** 공격 / 스킬1 / 스킬2 / 회피 버튼(쿨다운 숫자·암전 표시) + **AUTO 토글**(모드 표기)
- **좌측** 콤보 카운터(`12 HIT`), 중앙 상단 페이즈 배너 / 스킬 이름 / 회피 타이밍 안내

## 5. 검증 결과

로컬 정적 서버 + 헤드리스 Chromium(SwiftShader WebGL)으로 실제 실행해 확인했습니다.

- **기능 스모크 테스트: 19개 항목 전부 통과** (`tools/smoke.py`, 결과 `shots/smoke_report.json`)
  - 부팅/WebGL/텍스처 13종 로드, 포인터로 인트로 닫기, BGM 로드·재생·음소거,
    키보드 이동, 공격/스킬/회피 입력, 가상 조이스틱, AUTO 3단 순환,
    보스 페이즈 전환, 일시정지/재개, 승리, 재시작, **런타임/콘솔 오류 0**
- **스크린샷** (`shots/final/`, 2560×1440 = DPR 2배 캡처)
  - `01_intro.jpg` 인트로 타이틀
  - `02_battle.jpg` 일반전 — 적 접근·HP바·Lv 표기·데미지 숫자
  - `03_slash.jpg`, `04_impact.jpg` 검기 슬래시 + 타격 버스트
  - `05_boss_enter.jpg` 보스 등장 연출
  - `06_boss_fight.jpg` 보스전 HUD
  - `07_telegraph_perfect.jpg` **백색 예고 + "회피 타이밍!"**
  - `08_counter.jpg` **PERFECT COUNTER** 성공 순간
  - `09_boss_strike.jpg`, `10_victory.jpg`, `11_pause.jpg`
  - `12_portrait_guide.jpg` 세로 화면 회전 안내
- 캡처는 렌더 티커를 멈추고 1/60초 고정 스텝으로 진행 상태를 만들어 재현 가능하게 찍습니다

- 두 스크립트는 `pip install playwright && playwright install chromium` 환경에서 실행합니다.

  assets/               배경·캐릭터·몬스터 스프라이트, HUD 초상화

## 7. 알려진 한계 / 다음 단계

- 카엘·리아는 **정지 원화 1장**을 트랜스폼(호흡·전진·기울기·피격)으로 움직이는 방식입니다.
  진짜 스켈레톤 애니메이션이 필요하면 `guardian_dev_v14`의 리깅(rig) 에셋을 이식해야 합니다.
  (현재는 상반신 중심 구도라 타격 동작이 검기 이펙트에 의존합니다.)
- 몬스터는 정찰병 1종 + 보스 1종만 생성했습니다(요구 1~2종 충족). 추가 변형은 같은 파이프라인으로 확장 가능.
- 밸런스는 "AUTO로도 3분 내 클리어" 수준의 프로토타입 값이며, 실제 재미 검증용 튜닝은 더 필요합니다.
- 헤드리스 소프트웨어 렌더(SwiftShader)에서는 3~6fps로 측정되지만, 이는 GPU가 없는 환경 특성입니다.
  실제 모바일 GPU에서는 1280×720·얇은 오버드로 구성으로 60fps를 기대할 수 있습니다.
  (성능을 더 올리려면 안개/불티 해상도, HUD Graphics 매프레임 재드로잉을 정적 텍스처로 캐시)

### 디버그 훅 (검증용)
브라우저 콘솔에서:
```js
__debug.state()        // 페이즈/HP/적/보스/오류 확인
__debug.forceBoss()    // 즉시 보스 페이즈
__debug.freeze() / step(n) / unfreeze()   // 고정 스텝 진행 (캡처용)
__debug.killBoss()     // 보스 처치 → 승리 화면
__debug.setAutoMode('full'|'counter'|'manual')
```

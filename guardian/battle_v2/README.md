## 12. 지원 연출 전면 개편 (v5.3.0-build430, 2026-11-22)

### 12-1. 하단 큰 띠 → **왼쪽 컴팩트 컷인**
- 화면 아래를 가리던 사선 띠(y 512~720)를 **완전히 삭제**했습니다.
- 대신 화면 왼쪽 끝(x 10, y 150)에 **178×230 카드**(화면 면적의 **4.2%**)가 0.22초 밀려 들어와 1.04초 머물다 0.26초 만에 빠집니다.
- 카드 내용: 원형 초상화(지름 100) + 이름 + 영문 소속 + 기술명 + 효과 2줄. 전투 시야(가운데·바닥 예고·보스 HP·콤보 카운터 y 462)와 겹치지 않습니다.
- 지원 컷인은 여전히 **한 번에 한 장 + 최소 2.6초 간격**, 리아 컷인 중에는 양보합니다.

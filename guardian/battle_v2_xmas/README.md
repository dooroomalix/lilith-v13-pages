- 대기(호흡) · 이동(팔다리 보행, 이동 거리로 위상 동기) · 점프/착지 · 공격 1·2·3타 · 스킬 · 궁극기 · 피격 · 회피 · 쓰러짐이
  실제 관절 각도·위치 변화로 움직입니다. (Playwright 실측: 1타 팔 0.82rad, 3타 1.95rad, 스킬 0.90rad)

  몸에서 튀어나온 부위가 엉뚱한 파츠(다리 등)에 붙지 않습니다. (`tools_xmas/riggen.py`)

### 3. 3/4 시선 + 자연스러운 방향 전환
- 플레이어·적·보스 모두 **3/4 비스듬한 측면** 원화로 새로 그렸고, 서로 마주 보고 싸웁니다.

### 2. 성문 광장 등불 소등 & 재점화
- 광장에 **등불 4개**(x 214/468/756/1014, 바닥 앞뒤로 배치). 켜짐은 노란 유리+빛무리, 꺼짐은 검푸른 유리+연기.
- **소등**: 주기적 **암흑 바람**(7.0~10.5초, 페이즈가 오르면 ×0.78로 짧아짐)과 노엘의 공격(썰매 돌진·눈보라 배달 34% / 선물 소동 80%).
- **재점화**: 꺼진 등불 옆에서 `J`(공격)로 휘두르면 즉시, 그냥 다가가 0.75초 머물러도 자동으로 불이 붙습니다.
  3타(강타)는 범위가 넓어 근처 등불을 하나 더 살립니다.
- **빛의 온기**: 켜진 등불 1개당 공격력 +5%(4개 = 1.20배), 2개 이상이면 초당 회복(개당 0.8/s).
- **한기**: 4개가 모두 꺼지면 받는 피해 ×1.35 + 화면 가장자리 서리·어두워짐(캔버스로 그린 로컬 텍스처) + 전용 대사.
- HUD 등불 게이지(4칸)와 `빛의 온기 / 한기 · 등불 n/4` 라벨로 상태를 바로 읽을 수 있습니다.

### 3. 겨울 코스튬 & 연출
- 카엘 SD 위에 **붉은 목도리**(흰 털 장식) 오버레이 — 몸의 목 위치를 따라가며 자락이 흔들립니다.
- **성탄 설화 검기**: 외전에서는 검궤적이 검붉은 날 + 금빛 테두리로 바뀌고, 타격마다 눈가루가 흩날립니다.
- 노엘 등장 · 페이즈 · 등불 · 처치 대사를 자연스러운 구어체로 보강했습니다. **타 게임명 언급 0.**

### 4. 안정성
- 조작 체계 불변: ←/→·A/D 이동, W/S 깊이, ↑/Space 점프, J/K/L/Shift/Q/P(+M 소리, T 오토).
- `restart()`가 **등불 4/4 · 페이즈(P1) · 예고판 · `queuedJump` · 키/조이스틱/HUD 입력 · 컷인 · 대사**를 모두 초기화합니다.

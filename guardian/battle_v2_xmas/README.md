### 2. 관절(파츠) 리깅 — 통이미지 미끄러짐 폐기
- 한 장짜리 SD(`kael_sd_idle.png` 등)를 그대로 밀던 방식을 버리고,
  **머리 / 몸통 / 골반 / 상완·전완(좌우) / 허벅지·정강이(좌우) = 11파츠**로 잘라
  PixiJS 컨테이너 계층(`js/rig.js`)으로 리깅했습니다. 각 파츠는 자기 관절(pivot)에서 회전합니다.
- 대기(호흡) · 이동(팔다리 보행, 이동 거리로 위상 동기) · 점프/착지 · 공격 1·2·3타 · 스킬 · 궁극기 · 피격 · 회피 · 쓰러짐이
  실제 관절 각도·위치 변화로 움직입니다. (Playwright 실측: 1타 팔 0.82rad, 3타 1.95rad, 스킬 0.90rad)
- 적(스노우볼·미믹·루돌프)과 보스 노엘도 같은 리그로 이동·예고·공격·피격 모션이 살아났습니다.
- 파츠는 원화에서 **측지 거리(실루엣을 따라 번지는 거리) 보로노이**로 잘라, 검을 쥔 손에서 뻗은 칼날처럼
  몸에서 튀어나온 부위가 엉뚱한 파츠(다리 등)에 붙지 않습니다. (`tools_xmas/riggen.py`)

### 3. 3/4 시선 + 자연스러운 방향 전환
- 플레이어·적·보스 모두 **3/4 비스듬한 측면** 원화로 새로 그렸고, 서로 마주 보고 싸웁니다.
- 방향 전환은 `scaleX = -1` 즉시 반전이 **아닙니다**. 0.30초(17프레임) 동안
  머리 → 몸통 → 팔 → 다리 순서로 시간차를 두고 돌아가고, 그 사이 몸통이 폭 눌림(스쿼시),
  팔의 앞뒤 Z-order가 중간에 교차하며, 발밑 먼지와 살짝 기울기가 붙습니다.
  (Playwright 실측: 중간 yaw 값 11프레임, 프레임당 최대 Δyaw 0.21 — 한 프레임 뒤집힘 없음)

### 4. 완전한 스킨 교체 (덧씌우기 아님)
- **5인 × 3벌 = 15벌**을 통째로 새로 그렸습니다: **기본 전투복 / 산타 코트 / 다크 레드 연회복**.
- 스킨을 바꾸면 머리·몸통·팔·다리·무기 파츠 세트가 **전부 교체**됩니다(갑옷 위에 목도리만 얹는 방식 아님).
- 로비 카드 초상도 고른 스킨으로 바뀌고, HUD 초상·이름도 출전 캐릭터·스킨을 따라갑니다.
- 텍스처는 파츠별 파일 + 리그당 아틀라스 1장(`assets/rig/<rig>/atlas.webp`)으로 묶어 모바일에서도 가볍습니다.

### 5. 성능·안정성
- 필요한 리그만 지연 로딩(로비: 5인 기본복 + 고른 캐릭터 스킨 + 적/보스).
- Pixi 텍스처 GC 비활성 + WebGL 컨텍스트 손실 시 복구 대기, 4초 내 복구되지 않으면 1회 자동 새로고침.
- 적 사망 후 리그 업데이트 예외 가드.

### 그대로 유지한 것
